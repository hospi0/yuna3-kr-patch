## 대사 ✅(저장) / ⏳(참조)
- `YUNA3.DAT` 4,259,840B = **0x8000(32KB) 블록 130개**(129개 사용). 블록 = `[u16 A][u16 B][바이트코드 A-4 B][문자열 영역 B B @A]`.
  문자열 영역 = NUL 로 끝나는 SJIS/ASCII 연속. 대사 = `話者「本文` · 줄바꿈 0x0A + 탭 들여쓰기 · 뒤에 음성 경로(`/battle/ACM5153.ACM`) · 대사 ID(`MIK002`) 3개 한 묶음.
  예) 블록 0x40000: A=0x148A, B=0xA84, 문자열 196개, 대사 #87 = «ミキ「次の幕まで退散しますわ…».
- ✅**문자열 참조 = 문자열 기준점 S = 블록 + A + 6 에서의 u16 바이트 오프셋**(영역 앞 6바이트 `00 00 03 00 00 00` 뒤부터).
  근거(스테이트 `my files/2.state1`, 대화 «ユナ「うわ～～い！»): 블록 DAT 0x8000 이 Low RAM **0x00273460** 에 32KB 통째로 적재.
  VM 구조체 0x0609A420 = [+0 블록 시작][+0x18 코드 +6][+0x1C **S = +0x914**][+0x20 문자열 끝 +0x17B5][+0x24 +0x17B7], PC 0x0609A394 = 블록 +0x724,
  0x0609A39C = **0x5D** = 현재 대사 − S. 코드 +0x94 `5002 0000 054A 0000 005D 0000 0070` 에서 0x5D·0x70 확인.
- ✅**대사 명령 0x5002** = `[5002][0000][얼굴?][플래그][본문 오프셋][플래그][음성 오프셋]`(u16 7개, 플래그 값 다양) — 전 블록 1,849건 풀림(0xE8000 블록 20건 예외).
  일본어 문자열 3,240개 중 **1,828개가 0x5002 로 참조**. ✅**명령 길이 = 4 + 2×(op >> 12)**(전 129블록이 A+2 에서 정확히 끝남). 텍스트 인수 자리 전수(일본어 3,351/3,351, `tools/dat.py`):
  0x5002 인수2(블록 안 서브루틴 호출, arg0 = 대상 — 대상 533개 중 «대사/비대사 섞임» 0) · 0x50B7 인수3(전투 대사 1,022) · 0x2017 인수0(267) · 0x2013 인수1(메뉴) ·
  0x1017 인수0 · 0x60BF 인수1·5 · 0x6094 인수1·4 · 0x1046 인수0 · 0xB08B 인수2 · 0x3017 인수0. 원문 표 `work/text/dat_refs.tsv`(111,493자, 여러 번 참조 35).
- ✅블록 빈 공간: 사용 끝(마지막 0 아닌 바이트) 뒤 **최소 16KB**(0x240000 블록), 문자열 뒤 다른 데이터 없음 → **번역문을 블록 끝에 덧붙이고 참조 오프셋만 바꾸는** 방식이 공간상 가능(u16 범위 안).
- 분량(129블록): 대사 문자열 2,502(52,645자) · 중복 제외 **1,418문장 33,152자** · 음성 붙은 것 1,764 · 쓰인 글자 1,059종(한자 873).
